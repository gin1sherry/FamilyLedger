## 2. 已批准决议（编码时必须遵守）

1. 小票/订单 → 每条勾选项一条 `Record`，共享 `sourceBatchId`  
2. 全局 `monthlyBudget`（DataStore 或 `budgets.__all__`）  
3. 金额库内分，展示元  
4. 识别失败：`OFFLINE/TIMEOUT/HTTP/BAD_JSON/REFUSED` → 重试 / 转手动；超时 15s  
5. 聚合：`ProductMatcher` 规范化键 + 别名，非开放模糊  
6. F9 编辑删除 + 预算回算与 notified 重置  
7. 总预算 80% 也提醒；跨月自动恢复  
8. 无 Key / 无网时：识别不可用并提示；**记账浏览导出 Widget 全可用**  
9. P1-08：不写「≥80% 准确率」门禁，验收表见 PRD V1.1 第 10 章

## 7. 风险

| 风险 | 缓解 |
|------|------|
| 本机未装 Android SDK/Studio | 批准后先跑 Gradle；缺 SDK 则指引安装或 CI |
